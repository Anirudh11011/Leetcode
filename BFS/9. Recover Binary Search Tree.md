## 99. Recover Binary Search Tree

🔗 https://leetcode.com/problems/recover-binary-search-tree/

---

## 🧩 Problem

You are given the `root` of a binary search tree (BST), where the values of **exactly two** nodes of the tree were swapped by mistake.

Recover the tree **without changing its structure**.

---

## 📌 Examples

### Example 1:

**Input:**

```python
root = [1,3,null,null,2]
```

**Output:**

```python
[3,1,null,null,2]
```

**Explanation:**

`3` cannot be a left child of `1` because `3 > 1`. Swapping `1` and `3` makes the BST valid.

---

### Example 2:

**Input:**

```python
root = [3,1,4,null,null,2]
```

**Output:**

```python
[2,1,4,null,null,3]
```

**Explanation:**

`2` cannot be in the right subtree of `3` because `2 < 3`. Swapping `2` and `3` makes the BST valid.

---

## 🔒 Constraints

* The number of nodes in the tree is in the range `[2, 1000]`.
* `-2^31 <= Node.val <= 2^31 - 1`

**Follow up:** A solution using `O(n)` space is pretty straightforward. Could you devise a constant `O(1)` space solution?

---

## 💡 Approach (Inorder Traversal)

* An inorder traversal of a valid BST produces values in **sorted order**.
* If two nodes are swapped, the sorted order breaks at one or two places where `root.val < pred.val`.
* Maintain three variables:

  * `pred` → the previously visited node in inorder
  * `x` → the first misplaced node
  * `y` → the second misplaced node
* During the inorder traversal:

  * If `root.val < pred.val` (a violation):

    * Set `y = root`.
    * If this is the first violation → set `x = pred`.
    * Else (second violation) → both nodes are found, stop.
  * Update `pred = root`.
* Swap the values of `x` and `y` to fix the tree.

> If the swapped nodes are adjacent in inorder, there is only **one** violation, and `x = pred`, `y = root` from that single violation is enough.

---

## ⏱ Complexity

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(h)` for the recursion stack, where `h` is the tree height (`O(n)` in the worst case)

---

## 🧠 Solution (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def recoverTree(self, root: TreeNode | None) -> None:
        """
        Do not return anything, modify root in-place instead.
        """

        def fun(root):
            nonlocal x, y, pred

            if root is None:
                return

            fun(root.left)
            if pred and root.val < pred.val:
                y = root
                if x is None:
                    x = pred
                else:
                    return

            pred = root
            fun(root.right)

        x = y = pred = None
        fun(root)
        x.val, y.val = y.val, x.val
```
