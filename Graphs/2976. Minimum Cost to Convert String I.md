# 2976. Minimum Cost to Convert String I

🔗 https://leetcode.com/problems/minimum-cost-to-convert-string-i/

---

## 🧩 Problem

You are given two 0-indexed strings `source` and `target` of the same length consisting of lowercase English letters.

You are also given:

- `original[i]` → original character
- `changed[i]` → character it can be changed into
- `cost[i]` → cost of performing that conversion

In one operation, you may change a character `x` into `y` with cost `z` if there exists an index `i` such that:

- `original[i] == x`
- `changed[i] == y`
- `cost[i] == z`

A character may be converted through multiple intermediate characters if it results in a lower total cost.

Return the **minimum total cost** required to convert `source` into `target`.

If it is impossible to convert the string, return `-1`.

---

## 📌 Examples

### Example 1:

**Input:**

```python
source = "abcd"
target = "acbe"
original = ["a","b","c","c","e","d"]
changed = ["b","c","b","e","b","e"]
cost = [2,5,5,1,2,20]
```

**Output:**

```python
28
```

**Explanation:**

- `b → c` = 5
- `c → e` = 1
- `e → b` = 2
- `d → e` = 20

Total cost = `5 + 1 + 2 + 20 = 28`.

---

### Example 2:

**Input:**

```python
source = "aaaa"
target = "bbbb"
original = ["a","c"]
changed = ["c","b"]
cost = [1,2]
```

**Output:**

```python
12
```

**Explanation:**

Each `'a'` is converted as:

`a → c → b`

Cost per character = `1 + 2 = 3`

Since there are 4 characters:

Total cost = `3 × 4 = 12`.

---

### Example 3:

**Input:**

```python
source = "abcd"
target = "abce"
original = ["a"]
changed = ["e"]
cost = [10000]
```

**Output:**

```python
-1
```

**Explanation:**

There is no way to convert `'d'` into `'e'`, so the conversion is impossible.

---

## 💡 Approach (Dijkstra on Character Graph)

- Model the 26 lowercase letters as graph nodes.
- Each conversion rule forms a directed edge with the given cost.
- Since there are only **26 characters**, run **Dijkstra's algorithm** from every character to compute the minimum conversion cost to every other character.
- Store these shortest paths in a `26 × 26` matrix.
- Traverse both strings:
  - If characters are already equal, no cost is needed.
  - Otherwise, use the precomputed shortest cost.
  - If no path exists, return `-1`.
- Sum all conversion costs and return the total.

---

## ⏱ Complexity

- **Time Complexity:** `O(26 × (E log V) + n)`
  - `V = 26`
  - `E = len(cost)`
  - `n = len(source)`

- **Space Complexity:** `O(E + 26²)`

---

## 🧠 Solution (Python)

```python
class Solution:
    def minimumCost(
        self,
        source: str,
        target: str,
        original: List[str],
        changed: List[str],
        cost: List[int],
    ) -> int:

        adj_mat = [[] for _ in range(26)]

        for i in range(len(original)):
            adj_mat[ord(original[i]) - ord("a")].append(
                (ord(changed[i]) - ord("a"), cost[i])
            )

        def algo(adj_mat, start):
            h = [(0, start)]
            min_costs = [float("inf")] * 26

            while h:
                cur_cost, cur_char = heapq.heappop(h)

                if min_costs[cur_char] != float("inf"):
                    continue

                min_costs[cur_char] = cur_cost

                for next_char, change_cost in adj_mat[cur_char]:
                    new_cost = cur_cost + change_cost

                    if min_costs[next_char] == float("inf"):
                        heapq.heappush(h, (new_cost, next_char))

            return min_costs

        min_conversion_cost = [algo(adj_mat, i) for i in range(26)]

        total_cost = 0

        for s, t in zip(source, target):
            if s != t:
                char_conversion_cost = min_conversion_cost[
                    ord(s) - ord("a")
                ][ord(t) - ord("a")]

                if char_conversion_cost == float("inf"):
                    return -1

                total_cost += char_conversion_cost

        return total_cost
```
