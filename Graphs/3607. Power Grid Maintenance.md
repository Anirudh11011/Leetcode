## 3607. Power Grid Maintenance

🔗 [https://leetcode.com/problems/power-grid-maintenance/](https://leetcode.com/problems/power-grid-maintenance/)

---

## 🧩 Problem

You are given an integer `c` representing `c` power stations, each with a unique identifier `id` from 1 to `c` (1-based indexing).

These stations are interconnected via `n` bidirectional cables, represented by a 2D array `connections`, where each element `connections[i] = [ui, vi]` indicates a connection between station `ui` and station `vi`. Stations that are directly or indirectly connected form a power grid.

Initially, all stations are online (operational). You are also given a 2D array `queries`, where each query is one of the following two types:

* `[1, x]`: A maintenance check is requested for station `x`. If station `x` is online, it resolves the check by itself. If station `x` is offline, the check is resolved by the operational station with the smallest ID in the same power grid as `x`. If no operational station exists in that grid, return `-1`.
* `[2, x]`: Station `x` goes offline (i.e., it becomes non-operational).

Return an array of integers representing the results of each query of type `[1, x]` in the order they appear.

---

## 📌 Examples

### Example 1:

**Input:**

```python
c = 5
connections = [[1,2],[2,3],[3,4],[4,5]]
queries = [[1,3],[2,1],[1,1],[2,2],[1,2]]

```

**Output:**

```python
[3, 2, 3]

```

**Explanation:**

* Initially, all stations `{1, 2, 3, 4, 5}` are online and form a single power grid.
* Query `[1, 3]`: Station 3 is online, so the maintenance check is resolved by station 3.
* Query `[2, 1]`: Station 1 goes offline.
* Query `[1, 1]`: Station 1 is offline, so the check is resolved by the operational station with the smallest ID among `{2, 3, 4, 5}`, which is station 2.
* Query `[2, 2]`: Station 2 goes offline.
* Query `[1, 2]`: Station 2 is offline, so the check is resolved by the operational station with the smallest ID among `{3, 4, 5}`, which is station 3.

---

### Example 2:

**Input:**

```python
c = 3
connections = []
queries = [[1,1],[2,1],[1,1]]

```

**Output:**

```python
[1, -1]

```

---

## 🔒 Constraints

* `1 <= c <= 10^5`
* `0 <= n == connections.length <= min(10^5, c * (c - 1) / 2)`
* `connections[i].length == 2`
* `1 <= ui, vi <= c`, `ui != vi`
* `1 <= queries.length <= 2 * 10^5`
* `queries[i][0]` is either `1` or `2`.
* `1 <= queries[i][1] <= c`

---

## 💡 Approach (Disjoint Set Union & Reverse Query Processing)

* **Disjoint Set Union (DSU):** Use DSU to group connected power stations into distinct power grids based on the given connections.
* **Offline Processing via Reversal:** Since stations only go offline (and never come back online during the query stream), processing queries in reverse allows us to simulate stations turning back *online*.
* **State Tracking:**
* Pre-process the final online/offline states of all stations after all queries have been applied.
* Find the minimum-ID operational station for each grid component.
* Iterate through queries backwards: answering type `1` queries using current component states, and turning stations back `on` for type `2` queries while dynamically updating the minimum operational station ID per grid component.



---

## ⏱ Complexity

* **Time Complexity:** `O((c + n + q) * α(c))` — Where `c` is the number of stations, `n` is connections, and `q` is the number of queries, utilizing inverse Ackermann time bounds for DSU operations.
* **Space Complexity:** `O(c + q)` — To store DSU structures, query mappings, component trackers, and output results.

---

## 🧠 Solution (Python)

```python
class DSU:
    def __init__(self, size):
        self.parent = list(range(size))

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def join(self, u, v):
        self.parent[self.find(v)] = self.find(u)


class Solution:
    def processQueries(
        self, c: int, connections: List[List[int]], queries: List[List[int]]
    ) -> List[int]:
        dsu = DSU(c + 1)
        for p in connections:
            dsu.join(p[0], p[1])

        online = [True] * (c + 1)
        offline_counts = [0] * (c + 1)
        minimum_online_stations = {}

        for q in queries:
            op, x = q[0], q[1]
            if op == 2:
                online[x] = False
                offline_counts[x] += 1

        for i in range(1, c + 1):
            root = dsu.find(i)
            if root not in minimum_online_stations:
                minimum_online_stations[root] = -1

            station = minimum_online_stations[root]
            if online[i]:
                if station == -1 or station > i:
                    minimum_online_stations[root] = i

        ans = []
        for i in range(len(queries) - 1, -1, -1):
            op, x = queries[i][0], queries[i][1]
            root = dsu.find(x)
            station = minimum_online_stations[root]

            if op == 1:
                if online[x]:
                    ans.append(x)
                else:
                    ans.append(station)

            if op == 2:
                if offline_counts[x] > 1:
                    offline_counts[x] -= 1
                else:
                    online[x] = True
                    if station == -1 or station > x:
                        minimum_online_stations[root] = x

        return ans[::-1]

```
