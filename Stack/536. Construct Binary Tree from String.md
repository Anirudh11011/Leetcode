## 536. Construct Binary Tree from String

🔗 https://leetcode.com/problems/construct-binary-tree-from-string/

---

## 🧩 Problem

You need to construct a binary tree from a string consisting of parentheses and integers.

The whole input represents a binary tree. It contains an integer followed by zero, one or two pairs of parentheses. The integer represents the root's value, and a pair of parentheses contains a child binary tree with the same structure.

You always start to construct the **left** child node of the parent first if it exists.

---

## 📌 Examples

### Example 1:

**Input:**

```python
s = "4(2(3)(1))(6(5))"
```

**Output:**

```python
[4,2,6,3,1,5]
```

**Explanation:**

`4` is the root, `2(3)(1)` is its left subtree, and `6(5)` is its right subtree.

---

### Example 2:

**Input:**

```python
s = "4(2(3)(1))(6(5)(7))"
```

**Output:**

```python
[4,2,6,3,1,5,7]
```

**Explanation:**

Same as Example 1, but node `6` now has both a left child `5` and a right child `7`.

---

### Example 3:

**Input:**

```python
s = "-4(2(3)(1))(6(5)(7))"
```

**Output:**

```python
[-4,2,6,3,1,5,7]
```

**Explanation:**

Values can be negative. The root here is `-4`.

---

## 🔒 Constraints

* `0 <= s.length <= 3 * 10^4`
* `s` consists of digits, `'('`, `')'`, and `'-'` only.

---

## 💡 Approach (Iterative Stack)

* Helper `getNumbers(s, i)` parses a (possibly negative) integer starting at index `i` and returns the value and the index just after it.
* Start with an empty `root` node on the stack.
* Traverse the string with index `i`, popping the current node each step:

  * If `s[i]` is a digit or `'-'`:

    * Parse the number and assign it to `node.val`.
    * If the next character is `'('` → a left child follows: push `node` back, create `node.left`, and push it.
  * Else if `node.left` exists and `s[i] == '('`:

    * A right child follows: push `node` back, create `node.right`, and push it.
  * Else (`')'`):

    * The popped node's subtree is complete, so it stays off the stack.
* At the end, the remaining node on the stack (or `root`) is the answer.

---

## ⏱ Complexity

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(h)` for the stack, where `h` is the tree height (`O(n)` in the worst case)

---

## 🧠 Solution (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def str2tree(self, s: str) -> Optional[TreeNode]:
        if not s:
            return None

        def getNumbers(s, i):
            is_negative = False
            if s[i] == '-':
                is_negative = True
                i = i + 1

            number = 0
            while i < len(s) and s[i].isdigit():
                number = number * 10 + int(s[i])
                i += 1

            return number if not is_negative else -number, i

        root = TreeNode()
        stack = [root]

        i = 0

        while i < len(s):
            node = stack.pop()

            if s[i].isdigit() or s[i] == "-":
                value, i = getNumbers(s, i)
                node.val = value

                if i < len(s) and s[i] == "(":
                    stack.append(node)

                    node.left = TreeNode()
                    stack.append(node.left)

            elif node.left and s[i] == "(":
                stack.append(node)
                node.right = TreeNode()
                stack.append(node.right)

            i += 1

        return stack.pop() if stack else root
```
