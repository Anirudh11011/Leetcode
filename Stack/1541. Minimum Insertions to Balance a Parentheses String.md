## 1541. Minimum Insertions to Balance a Parentheses String

🔗 https://leetcode.com/problems/minimum-insertions-to-balance-a-parentheses-string/

---

## 🧩 Problem

Given a parentheses string `s` containing only the characters `'('` and `')'`, a string is **balanced** if:

* Any left parenthesis `'('` must have a corresponding **two consecutive** right parentheses `'))'`.
* Left parenthesis `'('` must go before the corresponding two consecutive right parentheses `'))'`.

In one operation, you can insert a character `'('` or `')'` anywhere in the string.

Return the **minimum number of insertions** needed to make `s` balanced.

---

## 📌 Examples

### Example 1:

**Input:**

```python
s = "(()))"
```

**Output:**

```python
1
```

**Explanation:**

The second `'('` has two matching `'))'`, but the first `'('` has only one `')'`. Add one more `')'` → `"(())))"`.

---

### Example 2:

**Input:**

```python
s = "())"
```

**Output:**

```python
0
```

**Explanation:**

The string is already balanced.

---

### Example 3:

**Input:**

```python
s = "))())("
```

**Output:**

```python
3
```

**Explanation:**

Add `'('` to match the first `'))'`, and add `'))'` to match the last `'('`.

---

## 🔒 Constraints

* `1 <= s.length <= 10^5`
* `s` consists of `'('` and `')'` only.

---

## 💡 Approach (Stack + Greedy)

* Use a stack `t` to track unmatched `'('`, and a counter `count` for insertions.
* Traverse the string with index `i`:

  * If `s[i] == '('` → push it onto the stack.
  * Else (`s[i] == ')'`):

    * If the next character is also `')'` → we have a full `'))'` pair, skip it (`i += 1`).
    * Otherwise → only a single `')'`, so insert one `')'` (`count += 1`).
    * Now match the `'))'` with a `'('`:

      * If the stack is non-empty → pop.
      * Else → insert a `'('` (`count += 1`).
* After the loop, each remaining `'('` in the stack needs `'))'` → add `len(t) * 2`.

---

## ⏱ Complexity

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)` (stack of unmatched `'('`)

---

## 🧠 Solution (Python)

```python
class Solution:
    def minInsertions(self, s: str) -> int:
        t = []
        count = 0
        i = 0

        while i < len(s):
            if s[i] == "(":
                t.append('(')
            else:
                if i + 1 < len(s) and s[i + 1] == ')':
                    i += 1
                else:
                    count += 1

                if t:
                    t.pop()
                else:
                    count += 1
            i += 1

        return count + len(t) * 2
```
