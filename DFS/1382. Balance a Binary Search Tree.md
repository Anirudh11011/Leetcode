# 1382. Balance a Binary Search Tree

🔗 [https://leetcode.com/problems/balance-a-binary-search-tree/](https://leetcode.com/problems/balance-a-binary-search-tree/)

---

## 🧩 Problem

Given the `root` of a **Binary Search Tree (BST)**, return a **balanced BST** with the same node values.

If there is more than one answer, return **any** of them.

A BST is considered **balanced** if the depth of the two subtrees of every node never differs by more than **1**.

---

## 📌 Examples

### Example 1:

**Input:**

```python
root = [1,null,2,null,3,null,4,null,null]
```

**Output:**

```python
[2,1,3,null,null,null,4]
```

**Explanation:**

The original BST is skewed to the right:

```text
1
 \
  2
   \
    3
     \
      4
```

One possible balanced BST is:

```text
    2
   / \
  1   3
       \
        4
```

Another valid answer is:

```python
[3,1,4,null,2]
```

---

### Example 2:

**Input:**

```python
root = [2,1,3]
```

**Output:**

```python
[2,1,3]
```

**Explanation:**

The tree is already balanced, so we can return it as is.

---

## 🔒 Constraints

* The number of nodes in the tree is in the range `[1, 10^4]`
* `1 <= Node.val <= 10^5`

---

## 💡 Approach (Inorder Traversal + Build Balanced BST)

### Key Observation

For a **Binary Search Tree**, an **inorder traversal** visits nodes in **sorted order**.

So:

1. Perform an inorder traversal and store all node values in an array.
2. The array is now sorted.
3. Build a balanced BST from the sorted array:

   * Pick the middle element as root.
   * Recursively build the left subtree from the left half.
   * Recursively build the right subtree from the right half.

Choosing the middle element ensures the heights of the left and right subtrees differ by at most `1`.

---

## ⏱ Complexity

* **Time Complexity:** `O(n)`

  * Inorder traversal: `O(n)`
  * Building balanced BST: `O(n)`

* **Space Complexity:** `O(n)`

  * Array to store inorder traversal.
  * Recursive call stack.

---

## 🧠 Solution (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def balanceBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:

        def inorder_fun(root, inorder):
            if not root:
                return

            inorder_fun(root.left, inorder)
            inorder.append(root.val)
            inorder_fun(root.right, inorder)

        def bfs(inorder, start, end):
            if start > end:
                return None

            mid = (start + end) // 2

            left = bfs(inorder, start, mid - 1)
            right = bfs(inorder, mid + 1, end)

            node = TreeNode(inorder[mid], left, right)
            return node

        inorder = []

        inorder_fun(root, inorder)

        return bfs(inorder, 0, len(inorder) - 1)
```

## ✅ Dry Run

For:

```python
root = [1,null,2,null,3,null,4]
```

### Step 1: Inorder Traversal

```python
inorder = [1, 2, 3, 4]
```

### Step 2: Build Balanced BST

* Middle of `[1,2,3,4]` → `2` becomes root.
* Left half `[1]` → left child = `1`
* Right half `[3,4]` → middle = `3`
* Remaining `[4]` → right child of `3`

Final tree:

```text
    2
   / \
  1   3
       \
        4
```

Balanced BST constructed successfully.
