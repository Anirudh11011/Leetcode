## 24. Swap Nodes in Pairs

🔗 https://leetcode.com/problems/swap-nodes-in-pairs/

---

## 🧩 Problem

Given a linked list, swap every two adjacent nodes and return its head.

You must solve the problem **without modifying the values** in the list's nodes (i.e., only the nodes themselves may be changed).

---

## 📌 Examples

### Example 1:

**Input:**

```python
head = [1,2,3,4]
```

**Output:**

```python
[2,1,4,3]
```

**Explanation:**

Pairs `(1,2)` and `(3,4)` are swapped.

---

### Example 2:

**Input:**

```python
head = []
```

**Output:**

```python
[]
```

**Explanation:**

An empty list stays empty.

---

### Example 3:

**Input:**

```python
head = [1]
```

**Output:**

```python
[1]
```

**Explanation:**

A single node has no pair to swap.

---

### Example 4:

**Input:**

```python
head = [1,2,3]
```

**Output:**

```python
[2,1,3]
```

**Explanation:**

`(1,2)` is swapped; `3` has no partner and stays in place.

---

## 🔒 Constraints

* The number of nodes in the list is in the range `[0, 100]`.
* `0 <= Node.val <= 100`

---

## 💡 Approach (Iterative with Dummy Node)

* Create a `dummy` node pointing to `head`, and set `prev = dummy`.
* While there are at least two nodes after `prev`:

  * `first = prev.next`, `second = first.next`
  * Rewire the pointers:

    * `first.next = second.next` → first points to the node after the pair
    * `second.next = first` → second now comes before first
    * `prev.next = second` → connect the previous part to the swapped pair
  * Move `prev` to `first` (now the second node of the swapped pair).
* Return `dummy.next` as the new head.

---

## ⏱ Complexity

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(1)`

---

## 🧠 Solution (Python)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def swapPairs(self, head: ListNode | None) -> ListNode | None:
        dummy = ListNode(0)
        dummy.next = head
        prev = dummy

        while prev.next and prev.next.next:
            first = prev.next
            second = first.next

            first.next = second.next
            second.next = first
            prev.next = second

            prev = first

        return dummy.next
```
